# Knowledge Schema

Durable knowledge lives as markdown notes with YAML frontmatter, one folder
per entity type. Frontmatter is the agent-facing API; prose is the
human-facing one.

| Folder | Type | Core frontmatter |
|---|---|---|
| `People/` | Person | `type, name, role, company, relationship, status, last-contacted, tags` |
| `Companies/` | Company | `type, name, status, tags` |
| `Meetings/` | Meeting | `type, date, attendees, status` |
| `Hypotheses/` | Hypothesis | `type, status, confidence, promotion-criteria, review-frequency` |
| `Insights/` | Insight | `type, status, confidence, previous-type, reclassified, reclassification-reason` (last three are permanent once set - never removed) |
| `Decisions/` | Decision | `type, status, confidence` |
| `Sources/` | raw evidence archive | `type=source, connector, occurred_at` |
| `Proposals/` | pending governance change | `claim_id, operation, action, status, target_note` |
| `Packs/` | compiled output | not a source of truth - generated by `second-brain compile`, never hand-edited |

## Hub-and-spoke linking

Person and Company notes are hubs: every other note type that references
them appends a link back, so a Person note accumulates its own history of
meetings, decisions, and insights without you maintaining that by hand.

## Hypothesis -> Insight lifecycle

- A **Hypothesis** is a belief being tested. It must state what evidence
  would promote it.
- An **Insight** is a conclusion backed by sufficient observed evidence.
- Promotion (Hypothesis -> Insight) and demotion (Insight -> Hypothesis,
  when support erodes) are both valid, expected transitions - not failures.
  Demotion's provenance fields (`previous-type`, `reclassified`,
  `reclassification-reason`) are permanent once set.
- A **Decision** records context, options considered, and outcome. A later
  claim with `operation=supersede` targeting the same note is how a
  decision changes over time without erasing what was previously true.

## Never orphaned

A concept that cannot be traced back to a Source should not exist in the
vault. Every durable note's `## Source` (or equivalent) section links back
to the claim(s) that produced it, which link back to the original evidence.
This is what makes "why does the vault say this" always answerable.

## The fictional Acme dataset

`examples/acme-vault/` (produced by `second-brain init --with-sample`)
shows this schema in use: a Company, two People, a Meeting, a Hypothesis,
an Insight that partially contradicts the Hypothesis, and a Decision that
gets superseded by a later one - the smallest set of entities that still
demonstrates every governance mechanism in this document.
